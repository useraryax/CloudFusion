
# ☁️ CloudFusion

### One Dashboard. Multiple Drives. Unified Storage.

CloudFusion is a modern cloud storage management platform that brings multiple Google Drive accounts together in one simple workspace. Connect up to 6 accounts, manage files, monitor combined storage, and intelligently route uploads.

## ✨ Features

- 🔗 Connect up to 6 Google Drive accounts.
- ☁️ Unified storage overview.
- 📁 Manage files and folders in one place.
- 🔍 Search across connected drives.
- 📤 Smart upload routing.
- 📊 Monitor storage usage.
- ⭐ Manage favorite and recent files.
- 📱 Responsive web interface.
- 🤖 Android-ready architecture.
- 🔐 Secure Google authentication.

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Google Drive API v3
- Google OAuth 2.0
- Capacitor (Android packaging)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/CloudFusion.git
```

### 2. Open the project

```bash
cd CloudFusion
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

## 🔑 Google API Setup

1. Create a project in Google Cloud Console.
2. Enable Google Drive API.
3. Configure Google OAuth 2.0.
4. Set up authorized redirect URLs.
5. Configure secure backend credentials.

Never expose private OAuth credentials or refresh tokens in frontend code.
